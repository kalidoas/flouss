# Design skill pointer

The authoritative Flouss design, motion, technical, screen, and proof requirements are in [REDESIGN_SPEC.md](REDESIGN_SPEC.md). Read and follow that specification for design and UI work.

This file previously contained a restrictive background-style kit. Its scope and style limits are superseded by `REDESIGN_SPEC.md`; do not apply those contradictory limits. Any guidance here that does not conflict with the specification may be used only as optional inspiration.
